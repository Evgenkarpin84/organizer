# Органайзер

Персональный органайзер-ассистент: PWA для Android, работает и на ПК. Пользователь один — владелец.

Модули: задачи и напоминания, разбор почты, дайджест новостей, привычки и чеклисты.

## Архитектура

- **Фронтенд:** Vite + React + TypeScript + Tailwind CSS, PWA через `vite-plugin-pwa`. Mobile-first, весь интерфейс на русском.
- **Данные и вход:** Supabase (Postgres, Auth, RLS). У каждой таблицы есть `user_id` и политики `user_id = auth.uid()`. Регистрация закрыта, доступ только у владельца. Вход по паролю (`signInWithPassword`): на бесплатном тарифе Supabase шаблоны писем заблокированы до подключения своего SMTP, поэтому код из письма отложен до этого момента.
- **Напоминания:** Web Push, отправляет Supabase (Edge Function + `pg_cron`), чтобы напоминания приходили при выключенном ПК.
- **«Мозг» (почта, новости):** скрипты на ПК, их запускает Планировщик Windows (задания «Органайзер — почта» каждые 30 минут и «Органайзер — новости» каждые 2 часа, заводятся `scripts/register-tasks.ps1`, журналы в `logs/`). Результаты пишутся в Supabase.
- **Почта:** напрямую по IMAP с паролями приложений — несколько ящиков на Mail.ru и Яндексе, адреса и пароли только в `.env`. Письма автоматически не отправляются, только черновики.
- **Хостинг:** GitHub Pages, репозиторий `Evgenkarpin84/organizer` (публичный), сайт https://evgenkarpin84.github.io/organizer/ раздаётся из ветки `gh-pages`. Публикация — `npm run deploy`.

## Правила

- Секреты (ключи Supabase, пароли IMAP) хранятся только в `.env`, он в `.gitignore`. В репозитории лежит `.env.example` с пустыми значениями.
- Ключ `service_role` из Supabase никогда не попадает во фронтенд.
- Тесты не требуют реальной базы или почты.
