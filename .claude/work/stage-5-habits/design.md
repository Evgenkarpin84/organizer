# Дизайн: привычки и чеклисты (этап 5)

Объём — больше одной страницы: этап добавляет вкладку с двумя секциями, два полноэкранных
маршрута и блок на «Сегодня». Блоки читаются независимо. Палитра, типографика, `FOCUS_RING`,
`Section`, `EmptyState` / `ErrorState` / `SkeletonList`, `BottomSheet`, правила доступности —
из `stage-0-1-tasks/design.md`. Приёмы ряда управления и разделения `View`/`Screen` — из
`stage-4-news/design.md`. **Новых цветовых токенов и новых иконок нет**: привычки — `habits`,
чеклисты — `tasks`, «Начать заново» — `repeat`, правка — `pencil`, удаление — `trash`, архив —
`archive`, отметка — `check`, создание — `plus`.

## Основной сценарий

1. Открыть приложение → «Сегодня» → блок «Привычки 2 из 3» под быстрым вводом.
2. Тап по чипу привычки → галочка появляется сразу (оптимистично).
3. Забытый вчерашний день: вкладка «Привычки» → тап по вчерашней клетке сетки.

Отметка за сегодня — **1 касание** с главного экрана. Закрыть пункт чеклиста — 2 касания
(вкладка → чеклист → пункт, 3-е касание и есть сама отметка). Создание привычки — 3 касания
(«＋» → «Новая привычка» → «Сохранить» после ввода названия).

## Главные цифры

| Где | Главная цифра | Единицы и период |
|---|---|---|
| «Сегодня», блок привычек | «2 из 3» в заголовке | «из» = запланировано на сегодня |
| Вкладка «Привычки», ряд управления | «Сегодня отмечено 2 из 4» — выше списка | сегодня |
| Строка привычки | серия справа от названия | «5 дней подряд» / «3 недели подряд» |
| Строка привычки, подпись | «71 % за 7 дней» | процент + явное окно 7 дней |
| Строка чеклиста | «5 из 12» | пунктов в текущем прохождении |

Слово «неделя» в подписи процента не используем: окно скользящее, а не календарное
(допущение 7 спеки) — пишем «за 7 дней», иначе цифра врёт о периоде.

## Вкладка «Привычки» (`src/screens/HabitsScreen.tsx`)

Заголовок «Привычки» уже в `TITLES` (`AppShell`), шапка не меняется; у `AppShell` слота для
кнопок экрана нет, поэтому создание живёт в ряду управления, как «＋» в `TasksScreen`.
Экран делится на `HabitsView` (чистый, данные пропсами — его покрывают тесты AC7) и
`HabitsScreen` (берёт данные из `useHabits`), как `NewsView` / `NewsScreen`.

### Ряд управления (один ряд, копия ряда `TasksScreen`)

```tsx
<div className="mb-2 flex items-center gap-2">
  <div role="tablist" aria-label="Набор привычек" className="flex flex-1 rounded-xl bg-slate-200 p-1">
    {([['active','Активные'],['archived','Архив']] as [HabitsViewMode, string][]).map(([key, label]) => (
      <button key={key} role="tab" type="button" aria-selected={mode === key} onClick={() => setMode(key)}
        className={`h-10 flex-1 rounded-lg text-sm font-medium ${FOCUS_RING} ${
          mode === key ? 'bg-white text-slate-900 shadow-sm' : 'text-slate-600'}`}>{label}</button>
    ))}
  </div>
  <button type="button" onClick={() => setCreateOpen(true)} aria-label="Создать привычку или чеклист"
    className={`flex h-11 w-11 items-center justify-center rounded-lg bg-blue-600 text-white ${FOCUS_RING}`}>
    <Icon name="plus" />
  </button>
</div>
<p className="mb-1 text-xs text-slate-500">Сегодня отмечено 2 из 4</p>
```

`mode` хранится в `useStoredState<HabitsViewMode>('habits.view', 'active')` (AC7). Строка
«Сегодня отмечено 2 из 4» показывается только в режиме «Активные» и только когда на сегодня
что-то запланировано.

Кнопка «＋» открывает `BottomSheet title="Что создать?"` с двумя кнопками
`h-12 w-full rounded-xl border border-slate-300 text-left px-3 text-sm` — «Новая привычка»
(`/habit/new`) и «Новый чеклист» (`/checklist/new`). Один сheet вместо двух кнопок в ряду:
ряд остаётся читаемым на 360 px.

### Порядок секций

`Section title="Привычки" count={…}` → `Section title="Чеклисты" count={…}`. Привычки первыми:
их отмечают ежедневно, чеклисты — раз в несколько недель. Разделения сложнее заголовков
(вкладок внутри вкладки, аккордеонов) нет — `mt-5` у `h2` из `Section` уже даёт паузу, а обе
секции короткие (5–10 строк). Секция с пустым набором не исчезает: вместо списка — своё
`EmptyState` (иначе непонятно, куда делись чеклисты).

Сортировка по умолчанию — `sortByPosition` (позиция, затем название): порядок создания,
ничего не прыгает после отметки. Сортировки по серии нет специально — список, который
переупорядочивается от отметки, невозможно запомнить пальцем.

### Строка привычки (`src/components/HabitRow.tsx`)

```tsx
<li className="mb-2 rounded-xl border border-slate-200 bg-white px-3 py-2.5">
  <button type="button" onClick={() => onOpen(habit)}
    className={`flex w-full min-h-11 items-start gap-2 text-left ${FOCUS_RING}`}>
    <span className={`mt-1.5 h-2 w-2 shrink-0 rounded-full ${LIST_COLORS[habitColor(index)].dot}`} aria-hidden="true" />
    <span className="min-w-0 flex-1">
      <span className="block text-[15px] leading-snug">{habit.title}</span>
      <span className="mt-0.5 block text-xs text-slate-500">
        {describeGoal(habit)} · {progress.percent} % за 7 дней
      </span>
    </span>
    <span className="mt-0.5 shrink-0 text-xs text-slate-500">{formatStreak(streak)}</span>
  </button>

  <div role="group" aria-label={`Отметки за 7 дней: ${habit.title}`} className="mt-2 flex gap-1">
    {week.map((day) => (
      <button key={day.iso} type="button" aria-pressed={day.done}
        aria-label={`${habit.title}: ${day.isToday ? 'сегодня, ' : ''}${day.weekdayLabel} ${day.dayOfMonth} — ${
          day.done ? 'отмечено' : day.scheduled ? 'не отмечено' : 'не запланировано, не отмечено'}`}
        disabled={!online || busy}
        onClick={() => onToggle(habit, day.iso)}
        className={`flex h-12 min-w-0 flex-1 items-center justify-center rounded-lg border text-[11px] ${FOCUS_RING} ${
          day.done ? 'border-transparent bg-blue-600 text-white'
            : day.scheduled ? 'border-slate-300 bg-white text-slate-500'
            : 'border-transparent bg-slate-100 text-slate-400'
        } ${day.isToday ? 'ring-2 ring-blue-200' : ''} disabled:opacity-60`}>
        {day.done ? <Icon name="check" className="h-4 w-4" /> : day.dayOfMonth}
      </button>
    ))}
  </div>
  <div aria-hidden="true" className="mt-1 flex gap-1">
    {week.map((day) => (
      <span key={day.iso} className="min-w-0 flex-1 text-center text-[11px] text-slate-500">{day.weekdayLabel}</span>
    ))}
  </div>
</li>
```

- **Сегодня и прошедший день отмечаются одинаково** — тапом по своей клетке. Отдельной большой
  кнопки «Отметить сегодня» в строке нет: она удвоила бы способ сделать одно и то же и
  оставила бы неясным, что делают клетки. Сегодняшняя клетка выделена `ring-2 ring-blue-200`
  (и всегда последняя справа), крупная цель за сегодня живёт на «Сегодня» — чип `h-11 w-11`.
- В неотмеченной клетке видно **число месяца**, а не пустота: по нему видно, на какой день
  попадёт тап. Подписи дней недели — отдельным рядом под сеткой, `aria-hidden`: для
  скринридера они уже внутри `aria-label` клетки, дублировать нельзя.
- Незапланированный день (цель «по пн, ср, пт») **тоже кликабелен**: лишняя отметка серию не
  ломает (AC4), а запрет на «сделал больше нормы» выглядел бы как поломка.
- Цвет точки — `habitColor(index) = LIST_COLOR_KEYS[index % 6]`, как `topicColor` у новостей.
  Цвет нигде не носитель смысла: статус клетки всегда продублирован галочкой/числом и
  `aria-pressed`.
- Тап по названию открывает `/habit/:id`. Область названия — единственная цель, кроме клеток.
- **В архиве** строка короче: название, `describeGoal`, подпись `text-xs text-slate-400`
  «В архиве», сетки и отметок нет — архивную привычку не отмечают, её возвращают из архива.

### Строка чеклиста (`src/components/ChecklistRow.tsx`)

```tsx
<li className="mb-2">
  <button type="button" onClick={() => onOpen(checklist)}
    className={`w-full rounded-xl border border-slate-200 bg-white px-3 py-2.5 text-left active:bg-slate-50 ${FOCUS_RING}`}>
    <span className="flex items-baseline gap-2">
      <span className="min-w-0 flex-1 text-[15px] leading-snug">{checklist.title}</span>
      <span className="shrink-0 text-xs text-slate-500">{progress.label}</span>
    </span>
    <span aria-hidden="true" className="mt-2 block h-1.5 overflow-hidden rounded-full bg-slate-200">
      <span className="block h-full rounded-full bg-blue-600" style={{ width: `${progress.percent}%` }} />
    </span>
    <span className="sr-only">Отмечено {progress.label} пунктов, {progress.percent} %.</span>
    <span className="mt-1 block text-xs text-slate-500">{statusLine}</span>
  </button>
</li>
```

`statusLine`: `startedAt === null && done === 0` → «Не начат»; идёт прохождение → «Начат
23 сентября»; иначе, если есть `lastCompletedAt` → «Пройден 23 сентября»
(`formatDayTitle(iso.slice(0,10), todayIso)`). Полоса `aria-hidden`, смысл — в `sr-only`:
`role="progressbar"` со `aria-valuenow` озвучивается хуже готовой фразы и требует лишних
атрибутов.

### Состояния вкладки

| Состояние | Что видно | Действие пользователя |
|---|---|---|
| Загрузка (первая) | Ряд управления + `SkeletonList count={3}` | ждать |
| Норма | Строка «Сегодня отмечено 2 из 4», две секции | тап по клетке / по чеклисту |
| Пусто: нет привычек | В секции «Привычки» — `EmptyState icon="habits"` «Привычек пока нет», hint «Например: зарядка, вода, чтение 20 минут», `action` — кнопка «Новая привычка» | создать |
| Пусто: нет чеклистов | В секции «Чеклисты» — `EmptyState icon="tasks"` «Чеклистов пока нет», hint «Например: сборы в поездку», `action` — «Новый чеклист» | создать |
| Пусто: архив | Один `EmptyState icon="archive"` «В архиве пусто», hint «Сюда попадают привычки и чеклисты, которые вы убрали из списка» | сегмент «Активные» |
| Ошибка загрузки, данных нет | Только `ErrorState` «Не удалось загрузить привычки. Попробуйте ещё раз.» + «Повторить»; пустых состояний нет (AC7) | «Повторить» |
| Ошибка обновления, данные есть | `ErrorState` над секциями, списки остаются рабочими (скелетон не подменяет список) | «Повторить» |
| Ошибка отметки (`actionError`) | Клетка возвращается в прежний вид (откат), под рядом управления `<p role="status" className="mb-2 rounded-lg bg-rose-50 px-3 py-2 text-xs text-rose-700">` «Не удалось сохранить отметку. Попробуйте ещё раз.»; гаснет после удачной отметки | повторный тап |
| Частичные данные | Привычки есть, чеклисты не пришли (или наоборот): пришедшая секция работает, `ErrorState` сверху один | «Повторить» |
| Нет сети | `OfflineBanner` из `AppShell`; клетки и чипсы `disabled`, под рядом управления `text-xs text-slate-500` «Нет сети — отметки недоступны» | включить сеть |

## Блок привычек на «Сегодня» (`src/components/HabitsToday.tsx`)

Между `QuickAdd` и `Section "Просрочено"` в `TodayScreen`. Заголовок повторяет классы `h2` из
`Section` (сам `Section` не подходит: нужен счётчик-строка «2 из 3» и ссылка справа).

```tsx
<section>
  <h2 className="mt-4 mb-2 flex items-center gap-2 text-sm font-semibold text-slate-600">
    Привычки
    <span className="rounded-full bg-slate-200 px-2 py-0.5 text-xs font-normal text-slate-700">
      {done} из {total}
    </span>
    <Link to="/habits" aria-label="Все привычки"
      className={`ml-auto flex h-11 w-11 items-center justify-center rounded-lg text-slate-500 ${FOCUS_RING}`}>
      <Icon name="habits" />
    </Link>
  </h2>

  {error ? (
    <p role="status" className="mb-2 rounded-lg bg-amber-100 px-3 py-2 text-xs text-amber-900">
      Привычки не загрузились. Задачи это не затронуло.
    </p>
  ) : null}

  <ul className="-mx-4 flex gap-2 overflow-x-auto px-4 pb-1 [scrollbar-width:none]">
    {scheduled.map((habit, index) => (
      <li key={habit.id} className="shrink-0">
        <button type="button" aria-pressed={doneToday} disabled={!online}
          aria-label={`${doneToday ? 'Снять отметку с' : 'Отметить'} «${habit.title}» за сегодня`}
          onClick={() => onToggle(habit, todayIso)}
          className={`flex w-[4.5rem] flex-col items-center gap-1 ${FOCUS_RING} disabled:opacity-60`}>
          <span className={`flex h-11 w-11 items-center justify-center rounded-full border-2 ${
            doneToday ? 'border-blue-600 bg-blue-600 text-white' : 'border-slate-300 bg-white text-slate-400'}`}>
            {doneToday ? <Icon name="check" className="h-5 w-5" /> : <span className={`h-2 w-2 rounded-full ${LIST_COLORS[habitColor(index)].dot}`} />}
          </span>
          <span className="w-full truncate text-center text-[11px] leading-tight text-slate-600">{habit.title}</span>
        </button>
      </li>
    ))}
  </ul>
</section>
```

- «2 из 3» — счётчик отмеченных среди запланированных на сегодня; ровно как на одобренном
  макете. Слово «из» вместо дроби и процента: на главном экране нужен факт, не показатель.
- Чипсы горизонтальные `-mx-4 … overflow-x-auto`: 4–5 привычек видны без прокрутки на 360 px,
  дальше лента листается тем же большим пальцем. Переноса в две строки нет — блок не должен
  расти и вытеснять задачи.
- Нет ни одной подходящей привычки **и** нет ошибки → блок не рендерится вообще (AC8). Если
  привычек нет из-за ошибки загрузки, рендерится только заголовок «Привычки» + amber-строка:
  иначе сообщение об ошибке было бы некуда положить. Ошибка привычек — amber, а не rose:
  задачи на экране целы, это частичные данные.
- Кружок неотмеченной привычки повторяет чекбокс `TaskItem` (`h-11 w-11` зона, `border-2`
  внутри), точка цвета внутри — единственное отличие. Отметка оптимистичная, откат при ошибке
  показывает ту же amber-строку с текстом «Не удалось сохранить отметку».

## Редактор привычки (`src/screens/HabitEditorScreen.tsx`, `/habit/new`, `/habit/:id`)

Полноэкранный маршрут по образцу `TaskEditorScreen` (аппаратная «Назад» закрывает редактор):
шапка «Отмена» — «Привычка» / «Новая привычка» — «Сохранить», тело `space-y-5 px-4 py-4`,
внизу `sticky` кнопка «Сохранить» `h-12 w-full rounded-xl bg-blue-600`.

Поля сверху вниз:

1. **Название** — `textarea rows={2}`, `text-lg`, `autoFocus` только для новой привычки,
   обрезка `slice(0, 80)`; счётчик `text-xs text-slate-400` с 60-го символа.
2. **Заметка** — `textarea rows={2}`, `text-sm`, `placeholder="Например: 20 минут, любая книга"`.
3. **Цель** — сегмент из трёх, классы как у «Повтор» в `TaskEditorScreen`
   (`flex rounded-xl bg-slate-200 p-1`, кнопки `h-10 flex-1`, `aria-pressed`): «Каждый день» /
   «Раз в неделю» / «Дни недели». Под ним — только нужное уточнение:
   - `times_per_week`: stepper «[−] 3 [+] раза в неделю», кнопки `h-11 w-11`, поле
     `h-11 w-14 text-center inputMode="numeric"`, зажим 1–7 (копия stepper интервала повтора);
     подпись `text-xs text-slate-500` «Любые дни — важно число за неделю».
   - `weekdays`: семь кнопок `h-11 w-11 rounded-full border` с `WEEKDAY_LABELS` и
     `aria-pressed`, выбранная — `border-blue-600 bg-blue-600 text-white` (как «Недели» у
     задач). Ни одного дня не выбрано → «Сохранить» неактивна + `text-xs text-rose-600`
     «Выберите хотя бы один день». Введённое не сбрасывается.
4. **Предпросмотр цели** — `aria-live="polite"`, `text-xs text-slate-500`:
   «Цель: по пн, ср, пт» (`describeGoal(draft)`). Одна строка вместо объяснений в подписях.
5. **Архив** — `h-12 w-full rounded-xl border border-slate-300 text-slate-700` с `Icon
   name="archive"`: «В архив» или «Вернуть из архива» (по `archivedAt`). Подпись
   `text-xs text-slate-500` «Из архива привычка не показывается на «Сегодня», отметки
   сохраняются». Подтверждения нет — действие обратимо в один тап.
6. **Удалить привычку** — `h-12 w-full rounded-xl border border-rose-200 text-rose-600`,
   только у существующей. `BottomSheet title="Удалить привычку?"`, текст «Отметки тоже
   удалятся, отменить будет нельзя», кнопки «Отмена» / «Удалить» (`bg-rose-600`).

Ошибка сохранения — `rounded-lg bg-rose-50 p-3 text-sm text-rose-700` над полями, поля не
очищаются, «Сохранить» снова активна. Привычка не найдена (прямой переход по ссылке) — экран
«Привычка не найдена» + кнопка «На главную», как в `TaskEditorScreen`.

## Экран чеклиста (`src/screens/ChecklistScreen.tsx`, `/checklist/:id`, `/checklist/new`)

Полноэкранный, шапка: «Назад» (текст) — название чеклиста `truncate` — кнопка `pencil`
`h-11 w-11`, `aria-pressed={editing}`, `aria-label="Правка"`.

**Режим прохождения**

```tsx
<div className="px-4 py-3">
  <div className="flex items-baseline gap-2">
    <p className="min-w-0 flex-1 text-sm text-slate-600">Отмечено</p>
    <p className="text-sm font-semibold">{progress.label}</p>
  </div>
  <span aria-hidden="true" className="mt-2 block h-1.5 overflow-hidden rounded-full bg-slate-200">
    <span className="block h-full rounded-full bg-blue-600" style={{ width: `${progress.percent}%` }} />
  </span>
</div>
<ul className="px-4">…</ul>
```

Пункт — разметка `TaskItem` без мета-строки: `li` `mb-2 flex items-start gap-3 rounded-xl
border border-slate-200 bg-white px-3 py-2.5`, слева `button role="checkbox"
aria-checked h-11 w-11` с кружком `h-6 w-6 border-2`, справа текст `min-w-0 flex-1 text-[15px]
leading-snug`, отмеченный — `text-slate-400 line-through`. Вся строка — одна цель: текст тоже
переключает пункт (в отличие от задачи, открывать нечего).

Низ, `sticky bottom-0 border-t border-slate-200 bg-white p-3 pb-[calc(0.75rem+env(safe-area-inset-bottom))]`:

```tsx
<div className="flex gap-2">
  <button type="button" onClick={() => setConfirmReset(true)}
    className={`h-12 flex-1 rounded-xl border border-slate-300 text-sm ${FOCUS_RING}`}>Начать заново</button>
  <button type="button" disabled={progress.done === 0 || busy} onClick={() => void complete()}
    className={`h-12 flex-1 rounded-xl bg-blue-600 text-sm font-medium text-white disabled:bg-slate-300 ${FOCUS_RING}`}>
    {progress.complete ? 'Завершить' : `Завершить (${progress.label})`}
  </button>
</div>
```

- «Завершить» неактивна при нуле отметок (AC9); при частичном прохождении в подписи стоит
  «5 из 12» — видно, что закрываешь неполный чеклист, и отдельного предупреждения не нужно.
- «Начать заново» при хотя бы одной отметке спрашивает `BottomSheet title="Начать заново?"`
  («Отметки 5 пунктов снимутся. Завершение записано не будет»), при нуле — ничего не делает
  (`itemsToReset` вернёт пустой список, лишнего запроса нет).
- После «Завершить» — тост `role="status"` (правило этапа 0–1) «Чеклист пройден» и возврат к
  нулевому прогрессу на том же экране: список пунктов остаётся, экран не закрывается.

**Режим «Правка»** (тот же экран, `editing === true`)

- Название чеклиста — `input h-12 w-full rounded-xl border text-base` (лимит 80).
- Пункт: `li` с `input h-12 min-w-0 flex-1 rounded-xl border border-slate-300 px-3 text-base`
  (лимит 120, сохранение по `blur` / Enter) + кнопка `trash` `h-11 w-11 text-rose-600`
  `aria-label={`Удалить пункт «${item.text}»`}`. Чекбоксы в правке не показываются: рядом с
  полем ввода они превращают строку в две мелкие цели.
- Удаление пункта — `BottomSheet title="Удалить пункт?"` с текстом пункта, «Отмена» /
  «Удалить» (AC9: подтверждение обязательно).
- Добавление — снизу списка `input placeholder="Новый пункт"` + кнопка «Добавить»
  (`h-12 shrink-0 rounded-xl bg-blue-600 px-4 text-sm font-medium text-white`, неактивна при
  пустом поле). Пункт уходит **в конец**, поле очищается и держит фокус — так вводится десять
  пунктов подряд без касаний. Порядок только «в конец», перетаскивания нет (спека, «не входит»);
  под списком подпись `text-xs text-slate-500` «Порядок — как добавляли».
- Внизу правки — «Удалить чеклист» `border border-rose-200 text-rose-600` с подтверждением
  («Пункты тоже удалятся») и «В архив» (`archive`), как у привычки.
- `/checklist/new`: тот же экран открывается сразу в правке с пустым названием, шапка «Новый
  чеклист», кнопка «Создать» вместо `pencil`. Пункты набираются в локальный черновик и
  сохраняются одним действием; после успеха — `navigate('/checklist/' + id, { replace: true })`,
  экран сразу в режиме прохождения.

**Состояния экрана чеклиста**

| Состояние | Что видно | Действие |
|---|---|---|
| Загрузка | `SplashScreen` (как у редактора задачи) | ждать |

## Доступность и удобство на телефоне

- **Клетки сетки** — `h-12` (48 CSS-px) при ширине ≈ 40 px на экране 360 px: семь дней обязаны
  влезть без горизонтальной прокрутки, поэтому ширина меньше 44 px. Компенсации: высота 48,
  `gap-1` между целями, тап обратим одним повторным нажатием (это toggle, а не разрушающее
  действие), и главная ежедневная цель — чип `h-11 w-11` на «Сегодня». Остальные цели экрана
  ≥ 44×44: чекбоксы пунктов, кнопки дней недели, «＋», кнопки листов.
- **Одной рукой**: на «Сегодня» отметка за сегодня — в верхней трети, но это одно касание по
  крупному чипу; все подтверждения — в `BottomSheet` у низа экрана; «Завершить» / «Начать
  заново» и «Сохранить» — `sticky bottom-0`. Прокрутка вкладки и лента чипсов работают тем же
  большим пальцем; кнопок в шапке `AppShell` этап не добавляет.
- **Крупный системный шрифт**: `min-h-*` у строки привычки и области названия, `flex-wrap` у
  подписей, `truncate` у названия чипа, `leading-tight` под чипом. Сетка держится на `flex-1`
  и не зависит от размера шрифта (в клетке `text-[11px]` и иконка). Подписи дней недели — две
  буквы, ряд не разваливается.
- **Контраст**: `text-slate-900` и `text-slate-600` на белом, `text-slate-500` для подписей,
  белый на `bg-blue-600` — AA. `text-slate-400` — только у числа в незапланированной клетке и
  у подписи «В архиве», и всегда рядом с текстовым дубликатом смысла.
- **Скринридер вместо цветных клеток**: у клетки `aria-pressed` + `aria-label`
  «Зарядка: вторник 23 — отмечено / не отмечено / не запланировано, не отмечено»; ряд клеток
  обёрнут в `role="group" aria-label="Отметки за 7 дней: Зарядка"`; подписи дней недели под
  сеткой `aria-hidden` (не дублировать). Полоса прогресса `aria-hidden` + `sr-only`
  «Отмечено 5 из 12 пунктов, 42 %». Точки цвета — `aria-hidden`. Чип на «Сегодня» —
  `aria-pressed` + `aria-label` «Отметить «Зарядка» за сегодня».
- **Порядок фокуса = порядок DOM**: сегмент «Активные / Архив» → «＋» → строка «Сегодня
  отмечено» (не фокусируется) → название привычки → 7 клеток слева направо (пн → сегодня) →
  следующая привычка → чеклисты → нижняя навигация. На «Сегодня»: `QuickAdd` → ссылка «Все
  привычки» → чипсы привычек → задачи. В `BottomSheet` — ловушка фокуса, Esc и возврат фокуса
  на вызвавшую кнопку (уже в компоненте).
- **Заголовки**: `h1` в `AppShell` / шапке маршрута, `h2` — «Привычки», «Чеклисты», «Привычки»
  на «Сегодня» и заголовок листа. Пропусков нет.
- `FOCUS_RING` на всех интерактивных элементах; текст ошибок без кодов, детали — в
  `console.error`.

## Что осознанно НЕ делаем

- Календарь-месяц и график привычки — спека фиксирует ровно 7 дней и окно 180 (бэклог).
- Отдельная крупная кнопка «Отметить сегодня» в строке привычки — второй способ сделать то же,
  что клетка «сегодня».
- Отметка дней старше 7 дней назад и будущих — в сетке их нет (допущение 3).
- Перетаскивание привычек, чеклистов и пунктов — «не входит» в спеке; порядок = порядок
  создания, об этом сказано подписью.
- Количественные привычки (стаканы, минуты) и «N раз в месяц» — модель хранит одну галочку.
- Напоминания о привычках и любые упоминания уведомлений в редакторе — нет механизма (бэклог).
- Чеклисты на экране «Сегодня» — они не привязаны к дате (допущение 14).
- История прохождений, «сколько раз проходил», экран статистики — нет таблицы (раздел 5 спеки).
- Свайпы «отметить / удалить» по строке и пункту — правило этапа 0–1: случайные жесты.
- Вкладки внутри вкладки («Привычки | Чеклисты») — два коротких списка помещаются на один
  экран, переключатель прятал бы половину модуля.
- Сортировка по серии и «проблемные привычки сверху» — список не должен переупорядочиваться
  после отметки.
- Тёмная тема, анимации заполнения клетки, офлайн-отметки — бэклог.

## Решения дизайнера (спорные места)

1. **Привычки выше чеклистов**, секции разделены только заголовками `Section`: привычки
   открывают ежедневно, чеклисты — эпизодически.
2. **Создание — один `BottomSheet` за кнопкой «＋»**, а не две кнопки в ряду управления: на
   360 px ряд с сегментом и двумя кнопками становится теснее, чем список из двух строк в листе.
3. **Сегмент «Активные / Архив» общий** для привычек и чеклистов: два независимых переключателя
   на одном экране никто не удержит, а архив — редкий режим просмотра.
4. **В архиве сетка отметок скрыта**: отмечать архивную привычку незачем, а живая сетка
   намекала бы, что она всё ещё считается.
5. **Клетка сетки — 40×48 px вместо 44×44**: семь дней без горизонтальной прокрутки важнее
   формального минимума; тап обратим, а крупная цель за сегодня есть на «Сегодня».
6. **В неотмеченной клетке — число месяца**, не пустой квадрат: иначе непонятно, куда именно
   ставишь галочку задним числом.
7. **Незапланированные дни кликабельны** (цель «по пн, ср, пт»): «сделал сверх нормы» не
   должно быть запрещено, серию это не ломает.
8. **Процент подписан «за 7 дней», а не «за неделю»**: окно скользящее (допущение 7), слово
   «неделя» читалось бы как календарная.
9. **Серия справа от названия, процент — в подписи**: серия мотивирует и меняется редко,
   процент — вспомогательный показатель.
10. **Блок на «Сегодня» рендерится при ошибке загрузки даже без привычек** — только заголовок и
    amber-строка: иначе сообщению об ошибке негде жить (AC8 требует строку внутри блока).
11. **Ошибка привычек на «Сегодня» — amber, а не rose**: задачи целы, это частичные данные;
    красный на вкладке «Привычки», где сломан весь экран.
12. **В режиме «Правка» чеклиста чекбоксы скрыты** — строка не должна быть одновременно полем
    ввода, чекбоксом и кнопкой удаления.
13. **«Завершить» показывает «Завершить (5 из 12)»** при неполном прохождении вместо
    предупреждающего листа: цифра честнее модалки и не добавляет шага.
14. **После «Завершить» экран не закрывается** — часто следом жмут «Начать заново» или
    проверяют список; возврат на вкладку был бы лишним касанием.
15. **Прогресс чеклиста — `sr-only`-фраза, а не `role="progressbar"`**: «Отмечено 5 из 12
    пунктов, 42 %» озвучивается понятнее набора `aria-value*`.
